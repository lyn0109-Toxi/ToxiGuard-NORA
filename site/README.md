# NORA TG-PTO-ET Public Site

This directory contains the static explanatory website for the TG-PTO-ET ontology and GP-L-CT rule demonstration.

- `index.html`: modular GitHub Pages entrypoint
- `index_single.html`: offline single-file version
- `styles.css`, `app.js`: presentation and interaction
- `data/`: ontology and demonstration data

GitHub Actions deploys this directory through `.github/workflows/pages.yml`.

Expected URL after GitHub Pages is enabled:

```text
https://lyn0109-toxi.github.io/ToxiGuard-NORA/
```

The public site explains NORA but does not replace the Streamlit assessment application.
