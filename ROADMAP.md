# NORA Product Roadmap

## v0.4 — GitHub foundation

- dedicated repository structure
- CI release gate
- scientific issue and PR templates
- TG-PTO-ET OWL/RDF and SHACL
- document provenance and assertion review
- deterministic Evidence Role engine
- Korean advisory reports

## v0.5 — Evidence workspace hardening

- richer page/table-level evidence anchors
- document-version comparison
- assertion conflict resolution
- rule-execution audit UI
- signed expert review record
- enhanced project import/export schema migration

## v0.6 — Retrieval-assisted review

- curated FDA/EMA/ICH source registry
- RAG retrieval with source/date/version gates
- LLM proposed assertions with structured confidence
- hallucination and unsupported-claim controls
- source freshness monitoring

## v0.7 — Multi-endpoint expansion

- nephrotoxicity
- cardiotoxicity
- immunotoxicity
- genotoxicity
- local tolerance

Each endpoint is released as a separate validated vertical slice.

## v0.8 — Secure pilot

- authentication and RBAC
- tenant isolation
- encrypted storage
- retention/deletion controls
- deployment and audit monitoring

## v1.0 — Expert-validated pilot product

- prospective pilot studies
- expert concordance metrics
- rule governance board
- customer-specific Context of Use profiles
- formal release and change-control process
